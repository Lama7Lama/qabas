# تشغيل الذكاء الاصطناعي

مزود الموقع الحالي Groq، والنموذج GPT-OSS 120B. يوجد إفصاح مختصر في «عن قبس» عن تحليل السبب وإجابة التطبيق. Gemini مخصص للمقارنة المصطنعة، ولا يستخدمه الموقع حاليا.

انسخ `.env.groq.example` إلى `.env.local`، وضع المفتاح بعد `GROQ_API_KEY=` و`QABAS_AI_PROVIDER=groq`. الاسم السابق `groq-evaluation` مقبول للتوافق؛ النطاق المعلن `learning`. اجعل الملف خاصا بالمستخدم (`chmod 600 .env.local`). لا تشارك المفتاح في المحادثة أو العرض أو المستودع.

```sh
npm run build
npm run serve:groq
```

افتح `http://127.0.0.1:4173/`. تغيير الإعداد أو التعليمات يحتاج إعادة التشغيل؛ تغيير المحتوى يحتاج إعادة البناء أيضا. `npm run serve` يستخدم Qwen المحلي افتراضيا عند غياب إعداد بيئي، ولا يحول طلبا تلقائيا بين المزودين. يمكن استعمال `QABAS_AI_PROVIDER=local` مع `.env.local` إذا أردت وضع Ollama صراحة.

لا يحتاج المتصفح مفتاحا. `/api/reflect` يمرر الاختيار المراجع وسببه فقط بعد الفحص. `/api/transfer-feedback` يرسل إجابة التطبيق ومعايير الموقف مرتين، دون عرض القراءة الأولى في الثانية. تنشر النقاط المتفقة فقط. التعليقات من المحتوى؛ لا فتاوى أو توليد أدلة أو درجات شخصية. البروتوكول القديم `/api/analyze` محذوف.

في خادم Node المحلي سقف 60 محاولة لكل عملية، وطلب واحد في الوقت نفسه ومهلة 45 ثانية. الفشل يستهلك السقف، ولا تعاد المحاولة تلقائيا. إعادة التشغيل تجدد السقف البرمجي؛ هذا لا يزيد حصة المزود. في Cloudflare يسمح كل طلب تطبيق بقراءتين ضمن المهلة، وتخص عدادات الدقيقة كل isolate. لا يفعّل الكود فوترة أو خطة مدفوعة؛ إعداد احتفاظ الحساب وحصته الفعلية يحتاجان تحققًا في حساب المزود. [Cloudflare](CLOUDFLARE.md).

للفحوص دون استدعاء النموذج:

```sh
npm test
npm run check:browser
```

فحص المتصفح يحتاج تشغيل المعاينة المحلية ومتصفح اختبار مثبتا. ردوده محاكاة لا تثبت دقة النموذج. لا تستخدم أدوات المقارنة القديمة في نسخة المصدر المختصرة؛ حفظ عميل Gemini واختباراته للتحقق من العقد فقط. الاختبار الدلالي يحتاج عينة مستقلة وتقييما بشريا، ولا يجوز تحويل تطابق أمثلة التطوير إلى دقة عامة.

[المخرجات المنظمة](https://console.groq.com/docs/structured-outputs)، [الحدود](https://console.groq.com/docs/rate-limits)، [البيانات](https://console.groq.com/docs/your-data)، [شروط الخدمة](https://console.groq.com/docs/legal/services-agreement). هذه مراجع المزود، وليست إثباتا لإعداد الحساب المستخدم.
