# تشغيل نسخة التحكيم

الاستضافة المختارة Cloudflare Pages. المشروع يستخدم رفع الحزمة المفحوصة بواسطة Wrangler؛ تحديث GitHub لا ينشر الموقع تلقائيا. [دليل Cloudflare والإعدادات](CLOUDFLARE.md).

الموقع متاح دون بيانات دخول خلف HTTPS، مع QABAS_ACCESS_MODE=public. تعتمد محتوى التطوير، وتبقى بوابة `build:release` مستقلة لاعتماد الصياغات ومعايير الفهم وحقوق المحتوى.

## تجربة محلية

```sh
npm ci --ignore-scripts
npm run build
npm run serve:groq
```

Node.js 22 أو أحدث. يوضع المفتاح في `.env.local` خارج Git، مع `QABAS_AI_PROVIDER=groq`. الرابط `http://127.0.0.1:4173/` محلي على الجهاز فقط. لا تشغلي API بواسطة خادم ملفات ثابتة أو GitHub Pages.

## الاستضافة والتحقق

```sh
npm test
npm run build:cloudflare
npm run check:cloudflare
```

بعد ضبط Secrets والأصل وحماية التعطل في Cloudflare، يستخدم `npm run deploy:cloudflare` إعادة البناء والفحص ورفع الملفات المطابقة للبصمات فقط. لا يرفع الشيفرة الخاصة أو ملفات البيئة أو العرض أو بيانات المشاركين. لا يوجد اسم مستخدم أو كلمة مرور للمستفيدين في هذا الوضع.

افحصي `/healthz`، وفتح الصفحة دون بيانات دخول، والرحلة من متصفح وجوال، واستجابة النموذج الفعلية. المعاينة المحلية ومحاكاة API لا تثبتان نجاح خدمة النموذج على الاستضافة. لا تفعلي الدفع تلقائيا؛ حصتا Cloudflare وGroq مستقلتان ومحدودتان.

عند التعطل أو نفاد حصة النموذج، يسمح قبس بمتابعة الشرح دون تعليق شخصي مصطنع. لا إعادة محاولة تلقائية ولا تحويل خفي إلى مزود آخر. عدادات Pages تخص كل isolate، وليست سقفا عالميا؛ نسخة التحكيم لم تختبر لجمهور واسع متزامن.

## الإصدار العام

استكملي اعتماد الصياغات ومعايير الفهم والحقوق، وترخيص الشيفرة، وسياسة التشغيل المناسبة للجمهور. فتح الوصول لا يمنح اعتمادا علميا. تجربة المستفيدين وقياس تغير الفهم تحتاجان اختبارا فعليا، ولا تستنتجان من نجاح الاختبارات البرمجية.
