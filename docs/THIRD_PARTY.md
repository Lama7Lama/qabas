# المصادر والتراخيص

الجرد يصف الملفات المستخدمة فعليا. لا يمثل شهادة توافق شاملة مع شروط المسابقة أو كل صور النشر.

| المكون | المصدر والترخيص | موضعه في المشروع |
|---|---|---|
| Tajawal Regular وBold | SIL OFL 1.1؛ الترخيص محفوظ في `src/web/fonts/OFL.txt` | خط النسخة النظيفة من GitHub، مع إشعار الحقوق المرفق |
| عام الإبل — The Year of The Camel | ملفات الهوية المقدمة، حقوق HadiType؛ [المصدر الرسمي](https://engage.moc.gov.sa/e/fonts/camel-year-fonts/?lang=ar) | ملفات خاصة في `work/private-fonts/` للمعاينة المحلية فقط، مستثناة من Git ومن بناء release. تصريح إعادة التوزيع غير موثق؛ لا ننسب إليه OFL |
| شعار وأيقونة قبس | ملفا SVG من الهوية المقدمة | الشعار الأفقي وأيقونة المتصفح في `src/web/brand/`. يجب التأكد من صلاحية حقوق الهوية للنشر المقصود |
| Node.js | [إشعارات تراخيص Node](https://github.com/nodejs/node/blob/main/LICENSE) | متطلب تشغيل خارجي؛ لا توزع ثنائياته داخل الموقع |
| Playwright وplaywright-core 1.62.1 | Apache-2.0، مثبتان في package-lock | تبعيات فحص فقط، لا تدخل بناء الموقع. `fsevents` الاختياري MIT. راجع إشعارات متصفح الاختبار إذا وزعت ثنائياته |
| Qwen3.5-4B | Apache-2.0 وفق [بطاقة المؤلف](https://huggingface.co/Qwen/Qwen3.5-4B) | خيار تشغيل محلي، الأوزان تحت work خارج Git والبناء |
| Ollama | [المستودع وترخيص MIT](https://github.com/ollama/ollama) | مشغل محلي منفصل؛ تراخيص تبعياته والثنائيات مهمة إذا أعيد توزيعها، لا توزع حاليا |
| GPT-OSS 120B عبر Groq | رخصة الأوزان منفصلة عن شروط خدمة الاستضافة | الموقع يستدعي الخدمة من الخادم؛ لا يوزع الأوزان أو المشغل أو المفتاح |
| Gemini عبر Google | شروط خدمة API | عميل مقارنة مصطنعة فقط، غير مربوط برحلة المستخدم |
| الأدلة والمصادر | الدرر السنية، الموسوعة القرآنية، المكتبة الشاملة؛ روابط الدليل محددة في المحتوى | لا تسحب شروح المواقع أو تنسخ مكتباتها إلى المشروع. مراجعة المصدر ليست تصريحا لنسخ أي محتوى محمي |
| قصص وشروح ومعايير قبس | حقوق السجلات `pending`؛ الاعتماد التحريري منفصل عن المراجعة العلمية | بناء release يرفض الحقوق والاعتمادات غير المستكملة |
| قالب عرض التحدي | PPTX مقدم من المستخدم، مع شعارات الجهات وصور وخطوط القالب | إعادة استخدام تخطيطات القالب في عرض التحدي فقط؛ لا تدخل أصوله موقع قبس أو مصدره العام |
| Readex Pro وUrbanist في العرض | SIL OFL 1.1 وفق مستودع [Readex Pro](https://github.com/google/fonts/tree/main/ofl/readexpro) و[Urbanist](https://github.com/google/fonts/tree/main/ofl/urbanist) | يحتفظ PPTX النهائي بخطوط القالب المضمنة. ملفات خطوط التحقق وترخيصها خارج Git، ولا يستبدل ذلك خط هوية الموقع |
| Cloudflare Pages وPages Functions | خدمة استضافة ومعالجة طلبات بشروط مزودها | نشر الحزمة المفحوصة بواسطة Wrangler؛ الإفصاح في «عن قبس» ودليل `CLOUDFLARE.md` |
| Wrangler وesbuild | تراخيص MIT وفق إشعارات الحزم المثبتة | أدوات بناء واختبار بإصدارات محددة؛ الثنائيات وnode_modules لا تدخل الاستضافة أو GitHub |

المعاينة تستخدم واجهات Node المدمجة، وخادم Cloudflare مجمع باستخدام Web APIs؛ لا توجد تبعيات npm خارجية في وقت تشغيل الموقع. النسخة القديمة وحزم Transformers/ONNX ومشغلاتها أرشفت محليا ولم تعد ضمن المصدر الحالي أو البناء.

لا يوجد ترخيص عام لشيفرة المشروع اختير نيابة عن مالكها. رفع المصدر إلى مستودع عام لا يمنح تلقائيا ترخيص إعادة استخدام شاملا، ولا يثبت حق إعادة توزيع أصل من طرف ثالث.

معالجة Groq معلنة في «عن قبس». المفتاح خاص بالخادم، ولا يفعّل الكود خطة دفع.
