# الأمان والخصوصية

المعاينة المحلية تعمل على `127.0.0.1:4173` فقط. نسخة التحكيم على Cloudflare Pages محمية بكلمة وصول خلف HTTPS. الموقع يستخدم Groq مع إفصاح في «عن قبس». الجمهور المستهدف 18 سنة فأكثر، دون تحقق عمر تقني. لا يرسل التطبيق إقرارات مخفية نيابة عن المستخدم.

## مسار البيانات

`POST /api/reflect` يستقبل `topicId, initial, revised`. يتحقق الخادم من بنية القرارين واختياراتهما وسببيهما، ثم يرسل الاختيار المراجع وسببه فقط، مع سياق محفوظ في المشروع. تصحيح الفهم لا يرفق تاريخ الإجابات.

`POST /api/transfer-feedback` يستقبل `topicId, answer`. يرسل إجابة التطبيق ومعايير الموقف إلى النموذج مرتين؛ القراءة الثانية لا ترى التصنيف الأول. ينشر نقاط الاتفاق فقط، مع اقتباس حرفي للحالات المؤيدة أو المناقضة. التعليقات من المحتوى، والخلاصة من قواعد المعايير المنشورة. النموذج نفسه قد يخطئ في المرتين؛ ليست مراجعة بشرية أو ضمانا للدقة.

لا قاعدة بيانات أو سجل للإجابات في قبس. الكتابة في ذاكرة الصفحة وتزول بإعادة التحميل. حفظ المرحلة اختياري ويقتصر على `stage, version`؛ الإصدار يتضمن معرف الموقف. هذا وصف لتخزين التطبيق، ولا يثبت عدم احتفاظ Groq بالنصوص. إعداد احتفاظ الحساب وZDR لم يتحققا. لا تصنيف للمعتقد أو التدين أو السمات الحساسة، ولا ملف دائم للمستخدم.

الجهة المختصة رابط اختياري إلى `https://alifta.gov.sa/` مع `noopener noreferrer` ودون نقل الإجابة أو معرف مستخدم. لا تكامل مراسلة أو اتفاق دعم معها. في وضع النموذج المحلي تذهب المعالجة إلى Ollama فقط، دون تحويل صامت إلى خدمة خارجية.

## الضوابط المنفذة

- Host وOrigin مطابقان للأصل المحدد؛ رفض cross-site واشتراط JSON وترويسة مخصصة، دون CORS. نسخة التحكيم تسمح بالانتقال الأعلى من رابط خارجي إلى صفحة محمية، مع استمرار رفض استدعاء API والموارد من أصل آخر.
- مسارا التحليل الحاليان فقط؛ `/api/analyze` القديم محذوف. العميل لا يختار سياسة أو معيارا أو مزودا أو عنوان اتصال.
- خدمة ملفات البناء فقط، وامتدادات محددة، والتحقق من المسار الحقيقي لمنع الخروج عبر رابط رمزي. المفاتيح وملفات المصدر والتقارير لا تخدم عبر HTTP.
- المفاتيح في `.env.local` بصلاحيات 0600، مستثناة من Git ومن البناء. `/api/config` يعرض المزود والنموذج والنطاق وحالة الإعداد فقط.
- رفض جسم طلب يتجاوز 8192 بايت؛ تجميع البايتات قبل فك UTF-8 لمنع فساد العربية بين أجزاء الشبكة. رفض JSON أو UTF-8 غير صالحين.
- 400 محرف لكل سبب أو إجابة، وطلب تحليل واحد متزامن و12 طلبا في الدقيقة. مهلة 45 ثانية مشتركة لتحليل التطبيق وتدقيقه. سقف عميل Groq مشترك 60 محاولة لكل عملية، يشمل الفشل؛ يعاد عند إعادة التشغيل، وليس حصة عالمية أو ضمانا ماليا.
- رفض البريد والروابط والأرقام الطويلة بالعربية والفارسية واللاتينية قبل طلب النموذج. هذا فلتر بيانات تواصل، لا إخفاء هوية كامل؛ قد تمر أسماء أو تفاصيل حساسة.
- حدود 65536 بايت لرد النقل ورفض UTF-8 غير صالح، مع مخطط إخراج محدد وتحقق من المعرفات والمقتطفات. لا عرض لتحليل خام أو نص حر من النموذج أو رسائل أخطاء المزود.
- ترميز النصوص قبل HTML، وسياسة CSP من نفس الأصل، ومنع التضمين في إطار و`nosniff` و`no-referrer` و`no-store`، وتعطيل الكاميرا والميكروفون والموقع.
- لا أدوات للنموذج أو تنفيذ أوامر أو وصول إلى الملفات. تعليمات المستخدم بيانات غير موثوقة؛ فحص البنية والاقتباس لا يضمن فهم المعنى أو صد كل حقن تعليمات.
- التعطل والغموض ونفاد الحصة لا تنتج حكما على الإجابة. التصحيح اختياري ومحدود، وتبديل الموقف أو تجاوز التعليق يلغي الاستجابة القديمة. لا إعادة محاولة تلقائية.

الرحلة المعتادة تحتاج ثلاثة استدعاءات: السبب مرة والتطبيق مرتين؛ قد يقل العدد عند الغموض أو يزيد بمحاولات اختيارية. الاختبارات المحفوظة مصطنعة، ولا تحتوي إجابات مستفيدين حقيقيين.

## حدود المراجعة والنشر

`serve-review.mjs` يتطلب أصلا HTTPS وكلمة وصول من 20–200 محرف ومفتاح Groq خاصا بالخادم. اسم الدخول `qabas`، والتحقق بواسطة Basic Authentication خلف TLS مع مقارنة ثابتة الزمن للبصمة. الحماية تشمل الصفحات والملفات وAPI. `/healthz` يعرض حالة عامة فقط، مع منع الفهرسة وHSTS. يجب أن يضبط وكيل الاستضافة رأس `X-Forwarded-Proto` وأن يمنع الوصول المباشر لمنفذ Node. لا ترسل كلمة الوصول في URL. فحوص هذه الضوابط الأربعة محلية بمحاكاة الخدمة، ولا تؤكد سلامة التكامل مع وكيل استضافة لم يجرب بعد.

بناء التحكيم يستخدم محتوى التطوير وخط Tajawal المرخص، ولا يغير شروط الإصدار العام. لا يتضمن الأسرار أو work أو أوزان النموذج أو الخط الخاص. [التشغيل](DEPLOYMENT.md).

فحوص HTTP والمتصفح والمفاتيح ليست اختبار اختراق مستقلا أو شهادة أمان. رفع المصدر إلى GitHub لا يجعل خادم المعاينة المحلي صالحا لاستضافة جمهور عام، ولا ينبغي وضع مفتاح في الواجهة أو GitHub Pages.

## Cloudflare Pages

البناء يجمع الخادم في `_worker.js` دون تبعيات Node في وقت التشغيل، ويحصر الملفات العامة بقائمة أصول محددة. يشمل التحقق من كلمة الوصول جميع المسارات، ويزيل الترويسات السرية قبل طلب الأصول. يرفض نطاقا غير `QABAS_PUBLIC_ORIGIN`، ولا يعرض ملفات الإعداد أو التقارير أو العرض التقديمي. إعداد `QABAS_LOCAL_PREVIEW` محلي فقط، ولا يوضع في الاستضافة.

يحفظ مفتاح Groq وكلمة الوصول في Secrets لدى Cloudflare. تمر النصوص عبر Cloudflare ثم Groq، دون قاعدة بيانات أو تسجيل نصوص في شيفرة قبس. هذا لا يثبت سياسات احتفاظ المزودين. عدادات الطلبات في Pages تخص كل isolate؛ سقف 60 محاولة السابق يخص عملية Node المحلية ولا يطبق كحصة عالمية على Cloudflare. طلب التطبيق يسمح بمحاولتين للنموذج ضمن مهلة مشتركة.

عند تعطل التحليل، يسجل الخادم رمز الحالة ونوع المهمة وHTTP إن وجد، دون إجابة أو اقتباس أو مفتاح أو رسالة مزود خام. لا تظهر هذه البيانات التشغيلية في واجهة المتعلم.

يجب ضبط `fail_open=false` لبيئتي Production وPreview والتحقق منه، حتى لا يتحول تعطيل الوظائف إلى تقديم الأصول دون مصادقة. النشر يستخدم الملفات المفحوصة وبصماتها فقط. نجاح الاختبارات المحلية لا يثبت نجاح النشر أو استيفاء CPU؛ يلزم فحص الرابط الفعلي. [التشغيل على Cloudflare](CLOUDFLARE.md).

رد الدعم المنقول يسمح بالمعالجة المحلية أو API ويطلب الإفصاح عن الخدمات ودورها في العرض. يجب إبقاء هذا الإفصاح وشرح البيانات المرسلة، ولا يعادل الرد اعتماد كل إجراءات الخصوصية أو شروط المزود أو تصريح كل الأصول.
