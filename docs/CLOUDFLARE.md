# تشغيل قبس محليا

يتطلب Node.js 22 أو أحدث ومفتاح Groq لتشغيل تحليل الإجابات.

1. انسخ `.env.groq.example` إلى `.env.local`، وضع مفتاحك في `GROQ_API_KEY`. اترك `QABAS_AI_PROVIDER=groq`.
2. شغل الأوامر التالية:

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run serve:groq
```

3. افتح `http://127.0.0.1:4173/`. بعد تعديل المحتوى، أعد البناء والتشغيل.

## الخدمات المستخدمة

في التشغيل المحلي يتصل خادم Node.js بخدمة Groq عبر نموذج GPT‑OSS 120B. وفي [الموقع المنشور](https://qabas-70m.pages.dev) يستضيف Cloudflare الموقع ويمرر طلبات التحليل إلى Groq. لا تحتاج إلى حساب Cloudflare أو نشر الموقع لتجربته محليا.

المفتاح في الخادم فقط. قبس لا يحفظ الإجابات في قاعدة بيانات؛ المعالجة الخارجية تخضع لسياسات المزودين. [تفاصيل الأمان والخصوصية](SECURITY.md).
