# قبس

تجربة تفاعلية لتعلم القيم الإسلامية من مواقف يومية: الرفق، الأمانة، التثبت، اجتناب الغيبة، اجتناب النميمة، وقد يكون فيما نكره خير.

**[تجربة الموقع](https://qabas-70m.pages.dev)** — متاح دون حساب أو كلمة مرور.

يستخدم GPT‑OSS 120B عبر Groq لفهم سبب الاختيار واختيار متابعة من محتوى معد مسبقا، والتعليق على التطبيق وفق معايير الموقف. يتحقق من الاقتباسات ويعرض نقاط اتفاق قراءتين من النموذج نفسه؛ الاتفاق لا يضمن الدقة. لا يولد فتاوى أو أدلة، ولا يصنف التدين أو السمات الحساسة.

## التشغيل محليا

Node.js 22 أو أحدث. انسخ `.env.groq.example` إلى `.env.local`، وضع مفتاحك في `GROQ_API_KEY`.

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run serve:groq
```

افتح `http://127.0.0.1:4173/`. المفتاح خاص بالخادم، ولا يرفع إلى GitHub أو يضاف إلى ملفات المتصفح.
