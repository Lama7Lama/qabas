# قبس

تجربة تعلم عربية تنطلق من مواقف يومية: اختيار التصرف، كتابة السبب، معلومة إضافية ومراجعة القرار، تفسير السبب ومتابعة مناسبة، الشرح والمصدر، ثم التطبيق في موقف مختلف.

الموضوعات: الرفق، الأمانة، التثبت، اجتناب الغيبة، اجتناب النميمة، وقد يكون فيما نكره خير.

GPT-OSS 120B عبر Groq يختار متابعة من المحتوى ويستشهد بعبارة حرفية من السبب. في التطبيق يصف معنى الإجابة وفق ثلاثة معايير خاصة بالموقف؛ قراءة ثانية من النموذج نفسه تحجب نقاط الاختلاف. لا يولد فتوى أو دليلا ولا يصنف تدين المستخدم أو سماته الحساسة. اتفاق القراءتين لا يضمن صحة التفسير.

## التشغيل والتحقق

```sh
npm ci --ignore-scripts
npm test
npm run build:cloudflare
npm run check:cloudflare
```

Node.js 22 أو أحدث. التطوير المحلي: `npm run build` ثم `npm run serve`. تشغيل Groq محليا يحتاج مفتاحا في `.env.local` خارج Git. لا يوضع مفتاح في JavaScript المتصفح أو vars في Wrangler.

## Cloudflare Pages

أمر البناء `npm run build:cloudflare`، الناتج `dist/cloudflare`. خادم Pages Functions مجمع في `_worker.js`، ومفتاح Groq في Secrets لدى المزود. الموقع متاح دون بيانات دخول عند QABAS_ACCESS_MODE=public؛ مفتاح النموذج يبقى في الخادم. اعتماد المحتوى العلمي وحقوقه مستقل عن فتح الوصول. [الإعداد والخصوصية](docs/CLOUDFLARE.md).

المشروع الحالي ينشر بواسطة `npm run deploy:cloudflare` بعد إعادة البناء والفحص. رفع المصدر إلى GitHub لا ينشر الموقع تلقائيا.

هذا المستودع يحتوي مصدر الموقع ومحتواه واختباراته وملفات البناء الضرورية. لا يضم مفاتيح أو بيانات مشاركين أو وثائق خاصة أو أوزان النموذج أو ملفات العرض أو الخط الخاص. الاختبارات لا تثبت نتائج تعلم بشرية أو نجاح نشر فعلي.
